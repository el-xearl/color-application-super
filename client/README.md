# Chromora Client

Frontend application for the Chromora cinematic palette platform.

---

## Stack

- React
- TypeScript
- TailwindCSS
- Framer Motion
- Chroma.js
- Axios

---

## Features

- Style explorer
- Dynamic palette generation
- Gradient system
- Palette export system
- Save/Delete palette integration
- Live UI preview
- 30-60-10 color rule preview

---

## Run Client

```bash
npm install
npm run dev
```
